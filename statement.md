# Project Statement & Scope

## Problem Statement
A basic Python program designed to help users quickly assess their Body Mass Index (BMI) and receive simple, clean dietary tips.

## Key Features
1. **BMI Calculation:** Computes BMI based on user input (height and weight).
2. **Category Classification:** Classifies results into WHO-standard categories.
3. **Basic Diet Tip:** Provides simple dietary advice aligned with the BMI category.
